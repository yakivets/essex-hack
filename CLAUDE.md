# CLAUDE.md — Agent & Contributor Guide

Guidance for coding agents (and humans) working in this repo. Read this first.

## What this is
**PactPilot** — an AI contract-review web app for the IADS Agentic AI Hackathon (48h). A
small-business founder drops in a contract and gets a 30-second risk **verdict**, an interactive
risk-highlighted **document**, market **benchmarks**, and a grounded **Q&A chat**. No login,
stateless.

## Tech stack
- **Frontend:** React + Vite + TypeScript (generated by Lovable), Tailwind. Talks to backend via REST.
- **Backend:** Python 3.11, **FastAPI only — no LangChain / no LangGraph.** Our own small async
  orchestrator runs the analysis steps (`asyncio.gather`); structured LLM output via an
  `llm_json(prompt, schema)` helper that parses the model's JSON into a Pydantic model.
- **AI:** **OCI Generative AI** called via the raw `oci` Python SDK — chat model for all reasoning,
  embedding model for vectors. The required OCI AI service. (No LangChain wrappers.)
- **Vector DB:** **Oracle Autonomous DB 23ai** AI Vector Search via the native `VECTOR` type +
  `VECTOR_DISTANCE` in plain SQL through `oracledb` (no `OracleVS`; simple in-memory cosine as the
  `FAKE_OCI` fallback). Collections/tables: `cuad_clauses` (market reference), `doc_clauses` (per-request, for chat).
- **Storage:** OCI Object Storage (ephemeral raw files). **Deploy:** OCI Compute (Ampere) — **the
  frontend bundle is served from OCI too** (nginx on the same VM, or an Object Storage static site).

**OCI-first (hard requirement):** the *entire deployed solution* runs on Oracle Cloud — UI bundle +
FastAPI + GenAI + 23ai + Object Storage. **No Vercel/Netlify/Lovable hosting** anywhere in the
product. Lovable builds the UI; OCI hosts it.

## The non-negotiable rule: the API contract is frozen
`docs/03-api-contract.md` and `backend/app/models/schemas.py` define the exact JSON shapes. The UI
and backend are built independently against them.
- **Never** rename or reshape a field without updating the contract doc AND `schemas.py` AND
  notifying the UI + backend owners in the same change.
- Backend returns a **canned `AnalysisResult` from day one**; real pipeline nodes replace it slice
  by slice. The UI must never break because a depth field is `null`/`[]`.
- Layer-1 fields (`verdict`, `key_facts`, `red_flags`, `document.clauses`) are guaranteed; depth
  panels are best-effort.

## Conventions
- Each analysis step (a plain async function) fills only its slice of `AnalysisResult` and is testable
  in isolation with a sample `clauses` list. Independent steps run concurrently via `asyncio.gather`
  (latency budget < 40s). No graph framework — just functions + the orchestrator.
- Structured LLM output via Pydantic models. Keep prompts beside the node that uses them.
- `segment(text) -> list[Clause{id,heading,text,start,end}]` is the pipeline's internal seam; char
  offsets drive UI highlighting — don't drop them.
- Frontend: all network calls live in `api.ts`; types mirror the contract; `VITE_API_BASE_URL`
  empty = mock mode.

## Running locally
- Backend: `pip install -r backend/requirements.txt`; set `FAKE_OCI=1` to stub all OCI calls;
  `uvicorn app.main:app --reload`.
- Frontend: `npm install && npm run dev`; leave `VITE_API_BASE_URL` empty for mock data.
- **No cloud access is ever required to run the app** (FAKE_OCI + mock mode).

## Guardrails for agents
- This is a 48-hour hackathon: **prefer the simplest thing that demos.** Don't add auth, accounts,
  databases-for-state, or features not in the brief's scope (`01-project-brief.md` → "Won't have").
- **OCI-first:** deploy/host only on Oracle Cloud. Never introduce Vercel/Netlify/third-party hosting
  or swap an OCI service for a non-OCI equivalent. `FAKE_OCI=1` + mock mode are **dev-only**; the
  judged demo must run on real OCI GenAI + 23ai. When unsure about OCI, see `docs/08-oci-onboarding.md`.
- Don't introduce a new framework/dependency without a clear reason; match existing patterns.
- Don't commit secrets, the OCI `~/.oci/config`, wallets, or `.env`. Use `.env.example`.
- Don't change shared interfaces (API contract, `Clause`, vector collection names) unilaterally.
- Commit/push only when asked. Small, scoped PRs per pod branch; don't push to `main` directly.
- "Not legal advice" — keep the disclaimer; this is a first-pass tool, not a lawyer.
